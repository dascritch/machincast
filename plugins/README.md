# Plugins

Each directory here is a MachinCast plugin, enabled in `machincast.toml`, section `[plugins]`
([#348](https://github.com/dascritch/machincast/issues/348)).
How to write one: [doc/fr/developpement/plugins.md](../doc/fr/developpement/plugins.md).

## Plugins

- [alternation](alternation/README.md): the shows in alternation, which share the same slot, one per week of the month ([#609](https://github.com/dascritch/machincast/issues/609)).
- [cartwall](cartwall/README.md): the cartwall, touch buttons in Machin intranet that act on the antenna ([#512](https://github.com/dascritch/machincast/issues/512)).
- [color_the_shows](color_the_shows/README.md): the colours of the shows by genre, or by priority, in the calendars and the airplay tables ([#628](https://github.com/dascritch/machincast/issues/628)).
