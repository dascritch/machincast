# La banque en emoji

Le plugin « Banque en emoji » met un emoji au début du nom interne d'une banque, par exemple « 🌟 Publicités » : les tableaux d'airplay et des sonores à venir, qui montrent le nom interne, la font reconnaître d'un coup d'œil ([#505](https://github.com/dascritch/machincast/issues/505)).

## Choisir l'emoji d'une banque

1. Ouvrir la fiche de la banque.
2. Dans la ligne **Nom interne**, choisir l'emoji dans le sélecteur, devant le nom : la liste en propose quelques-uns ; tout autre emoji peut s'y écrire ou s'y coller, par exemple depuis le sélecteur d'emojis du bureau.
3. Enregistrer.

Le nom interne éditable ne montre pas l'emoji : il est enregistré au début du nom, suivi d'une espace.
Vider le sélecteur retire l'emoji ; un texte qui n'est pas un emoji est refusé, à l'enregistrement.
Le raccourci du libellé, Alt+N, va au nom sans emoji.

Une banque dont le nom commençait déjà par un emoji suivi d'une espace le montre dans le sélecteur, sans rien à refaire.
Désactivé, le plugin laisse les noms internes tels qu'ils sont, emoji compris.
