# Plugins

Chaque répertoire d'ici est un plugin de MachinCast, activé dans `machincast.toml`, section `[plugins]`
([#348](https://github.com/dascritch/machincast/issues/348)).
Pour en écrire un : [doc/fr/developpement/plugins.md](../doc/fr/developpement/plugins.md).

## Plugins

- [cartwall](cartwall/README.md) : le cartouchier, des boutons tactiles dans Machin intranet qui agissent sur l'antenne ([#512](https://github.com/dascritch/machincast/issues/512)).
