# Aide sur la liste des événements

![L'onglet Événements, ses éléments numérotés comme ci-dessous](../../captures/aide/liste-evenements.png)

L'onglet Événements donne tous les événements, du plus prioritaire au moins prioritaire, puis par nom.
Les numéros renvoient à l'image ; **Aide → Aide contextuelle**, ou <kbd>F1</kbd>, donne chacune de ces aides en infobulle, sur l'élément lui-même.

1. **Filtrer…** (`filter_`) : ne garde que les lignes dont une colonne contient le texte tapé, sans tenir compte des majuscules ni des accents.
2. **Compte** (`count`) : combien de lignes restent, sur combien.
3. **Nouvel événement** (`new`) : ouvre une fiche vide ; rien n'est en base avant **Enregistrer**.
4. **Liste** (`table`) : ⚠️, nom, nom public, priorité, début, fin, récurrence et anomalie ; la priorité se trie par importance. Le clic droit propose **Dupliquer**. Un clic sur le titre d'une colonne trie, un double-clic ou <kbd>Entrée</kbd> ouvre la fiche, le clic droit sur les titres choisit les colonnes.
